# Arkanoid Clone

Juego HTML simple inspirado en Arkanoid. Este proyecto incluye un solo archivo: `arkanoid.html`, que contiene el juego completo en HTML, CSS y JavaScript.

## Cómo jugar

1. Abre `arkanoid.html` en tu navegador web.
2. Usa las teclas `←` y `→` para mover la pala.
3. Presiona `Espacio` para lanzar la bola.
4. Destruye todos los ladrillos para avanzar de nivel.
5. Si pierdes todas tus vidas, el juego termina.

## Características

- Controles de teclado y soporte táctil básico.
- Efectos de sonido usando Web Audio API.
- Varias mejoras temporales (`power-ups`) como bola lenta, bola rápida, multibola, pala grande/pequeña y super bola.
- UI con puntaje, nivel y vidas.
- Diseño responsivo y adaptado a pantallas pequeñas.
- Accesibilidad básica: `aria-live`, `aria-labels`, y enlace de salto al canvas.

## Requisitos

- Navegador moderno con soporte para Canvas y Web Audio API.

## Notas

- El audio se inicializa en la primera interacción del usuario.
- No se requiere servidor: simplemente abre el archivo localmente.
